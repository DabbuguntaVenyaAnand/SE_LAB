## Run

```bash
cd maze-runner
python -m pip install -r requirements.txt
python main.py
```

The updated game includes difficulty selection, a shortest-path hint, fog of war and a persistent timer leaderboard. Choose a difficulty to start. Use arrows or WASD to move, H to toggle the hint and R to generate another maze.
